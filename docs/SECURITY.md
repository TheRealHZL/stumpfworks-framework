# Security Policy

SWF is pre-1.0 software and is not yet recommended for production use.

Please report suspected vulnerabilities privately to the StumpfWorks maintainer.
Do not include credentials, personal data, or working exploits in public issues.
The permanent private reporting address will be added before the first public
release.

Security-sensitive changes require negative tests. Cryptographic algorithms must
come from established, maintained libraries; custom cryptography is not accepted.
