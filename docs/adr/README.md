# Architecture Decision Records

ADRs preserve consequential technical decisions and their context. Existing
accepted records are not silently rewritten when a decision changes; add a new
record and mark the old one superseded.

New files use the next four-digit number and this structure:

```markdown
# ADR NNNN: Decision title

- Status: Proposed | Accepted | Superseded by ADR NNNN
- Date: YYYY-MM-DD

## Context
## Decision
## Consequences
```
