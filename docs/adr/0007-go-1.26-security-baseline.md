# ADR 0007: Go 1.26 security baseline

- Status: Accepted
- Date: 2026-09-12

## Context

The first scaffold used the locally installed Go 1.24.4 toolchain and pgx 5.8.0.
An immediate `govulncheck` run found reachable vulnerabilities in the standard
library and `GO-2026-5004` in pgx. Fixed current pgx and `x/text` releases also
require a newer Go toolchain.

## Decision

Require Go 1.26 or newer, pgx 5.11.0 or newer within the compatible major line,
and a fixed `golang.org/x/text` release. Pin the vulnerability scanner in CI and
fail the workflow when reachable vulnerabilities are reported.

## Consequences

Developers and build images must provide Go 1.26. The project does not retain an
older vulnerable toolchain merely for local convenience. Any future minimum-Go
change requires a recorded compatibility and security reason.
